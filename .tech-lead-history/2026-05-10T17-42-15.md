### [Tech Debt] Оформить публикацию пакета: scripts + exports + WC bundle Button/Typography
- Что нарушено: WC entry собирается только ручной командой (`vite build --mode web-components`), npm-скрипта нет. В `package.json` отсутствуют `exports`, `main`, `module`, `types`, `files` — Vue-консьюмер не может импортировать кит по имени. В WC entry зарегистрированы только `Input`/`InputPassword`/`EyeToggle`; для `Button` и `Typography` выбран Vue SFC, но единого артефакта импорта (`ui-kit/vue`) тоже нет — консьюмеру придётся тянуть `.vue` по относительному пути.
- Как исправить: добавить скрипты `build:web-components` и `build:vue` (барель `*.vue`), описать `exports` в `package.json` для трёх точек входа (`.`, `./web-components`, `./vue`), зафиксировать список `files`.
- Специалист: frontend
- Сложность: medium
- Срочность: высокая

**Анализ:**
Кит готов наполовину: код есть, но «дверь наружу» не открыта — Vue-консьюмер `tg_parser` не может написать `import 'ui-kit/web-components'` или `import { Button } from 'ui-kit/vue'`. Нужно: (1) `package.json` → `exports` с тремя условиями, `main`/`module`/`types` для основного React-экспорта, `files: ["dist"]`, (2) скрипты `build:web-components` и `build:vue` плюс агрегатный `build:lib` (последовательно три вызова `vite build`), (3) проиндексировать Vue-порты — `src/shared/ui/vue/index.ts` либо отдельный entry, который реэкспортирует `Button.vue` и `Typography.vue` (Vite library mode со включённым `@vitejs/plugin-vue`). Не трогать SPA-демо (`src/App.tsx`, `src/main.tsx`) и базовый путь `/ui-kit-animations/` для Storybook/gh-pages — сборка библиотеки идёт в свои `dist/*`. Решить, попадают ли в WC bundle Button и Typography (по текущему коду — нет; зафиксировать выбор в README одной строкой, чтобы консьюмер знал, что Button/Typography доступны только как Vue SFC и React).

**План:**

2. Добавить `build:web-components` (`vite build --mode web-components`), `build:vue` (`vite build --mode vue`), `build:lib` (объединяющий) и подключить `@vitejs/plugin-vue` под условный mode в `vite.config.ts`.
3. Создать `src/shared/ui/vue/index.ts` (или второй entry), экспортирующий `Button.vue` и `Typography.vue`.
